# QnnProbe

Proves whether ONNX Runtime's QNN execution provider actually executes a graph
on the Hexagon NPU **from C#**, and which attachment API is required.

```powershell
dotnet run -c Release --project src\csharp\QnnProbe
```

It loads `src/setup/_qnn_probe.onnx` — the small quantized graph generated by
`check_qnn.py --prove-npu` — three ways and counts node placement from the ORT
profiler, because a successful `Run()` is not evidence of placement.

Pass a path to probe a different model, and `--register-first` to check whether
the provider list behaves differently when registration precedes the first
query (it does not).

See the README section "Calling ONNX Runtime directly" for the results and what
they mean.
